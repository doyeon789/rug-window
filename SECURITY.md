# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately through GitHub's private vulnerability reporting:
[Security → Report a vulnerability](https://github.com/pizza-playground/rug-window/security/advisories/new).
Include what you found, how to reproduce it, and which version you used.

This is a hobby project maintained by one person, so there is no guaranteed
response time, but reports are taken seriously and you will get an answer.

## Scope

Rug Window runs locally with your user's permissions. It reads desktop icon
positions from Explorer's memory and makes no network connections. Things
worth reporting include, for example, a way for another program or file to
make Rug Window run code, or a problem in the release zip itself.
